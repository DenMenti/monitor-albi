    Collega GitHub

    Serve un "token", una chiave personale che permette a questa pagina di avviare i controlli e salvare le impostazioni. Si crea una volta:

    1. Apri github.com → Fine-grained token.
    2. Nome: "Monitor albi". Scadenza: quella che preferisci.
    3. Repository access: Only select repositories → scegli questo repository.
    4. Permissions → Repository: Actions Read and write, Contents Read and write.
    5. Genera, copia il token e incollalo qui sotto.
    Il token resta salvato solo in questo browser. Su un computer condiviso premi "Scollega" quando hai finito.
